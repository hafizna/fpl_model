Memuat konfigurasi operator…

Dokumen ini menjelaskan batas data pada closed alpha. Ini adalah artefak produk yang harus ditinjau penasihat hukum operator sebelum tester nyata diundang; keberadaannya sendiri bukan bukti kepatuhan hukum.

Operator Kontak privasi/support Hosting · Retensi log aplikasi

Data yang diproses

  • Kode akses tester dikirim melalui header HTTPS. Plaintext disimpan hanya di sessionStorage browser; server dikonfigurasi dengan digest SHA-256.
  • FPL Team ID yang Anda masukkan dipakai untuk meminta squad publik dari API FPL. Aplikasi tidak menyimpan Team ID atau squad tersebut dalam database server.
  • Squad, estimasi selling price, susunan terakhir, dan rating terakhir disimpan di localStorage browser Anda dan dapat dihapus melalui pengaturan site data browser.
  • Log aplikasi memuat request ID acak, template route, metode, status, dan durasi. Log tidak memuat URL mentah, Team ID, request body, squad, atau kode akses.
  • Receipt rekomendasi memuat hash input/output, ID release, dan ID keputusan—bukan Team ID atau daftar squad. Receipt tidak dipersistenkan oleh server.

Tujuan dan pihak lain

Data diproses untuk membuka akses alpha, mengambil squad publik yang Anda minta, menghitung rekomendasi, mencegah penyalahgunaan, dan mendiagnosis insiden. FPL menyediakan sumber squad publik; penyedia hosting yang tercantum di atas dapat memproses data jaringan dan log sesuai konfigurasi operator. Tidak ada akun, payment, iklan, analytics, atau cookie pemasaran pada build ini.

Retensi, keamanan, dan pilihan Anda

State squad berada di browser sampai Anda menghapus site data. Log aplikasi dipertahankan selama periode di atas. Tutup sesi/tab dan hapus site data untuk menghapus kode akses dan state lokal. Hubungi alamat support untuk permintaan akses, koreksi, pembatasan, atau penghapusan data yang mungkin dikuasai operator, serta untuk melaporkan insiden.

Dasar regulasi dan perubahan

Operator harus mengonfirmasi dasar pemrosesan, peran pengendali/prosesor, transfer lintas negara, prosedur hak subjek, dan respons insiden sebelum alpha nyata. Referensi utama adalah UU Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi. Versi notice akan berubah bila data flow, hosting, analytics, account, atau payment berubah.
